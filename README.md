## 🚀 Featured Projects

### 01. Real-Time Human Emotion Detection System

**Computer Vision · Deep Learning · CNN**

A webcam-based facial emotion recognition application that detects faces and predicts emotions using a CNN model.

- Recognizes seven emotion categories.
- Uses OpenCV Haar Cascade for face detection.
- Processes facial images in grayscale at 48 × 48 resolution.
- Displays emotion predictions and probability scores through a Flask web dashboard.
- Includes camera start/stop functionality and a responsive interface.

**Technology:** Python · TensorFlow · Keras · OpenCV · Flask · JavaScript

[View Project Repository](https://github.com/ProjectByAbhi/Real-Time-Human-Emotion-Detection-System)

**Technology:** Python · Pandas · Scikit-learn · Random Forest · Streamlit
